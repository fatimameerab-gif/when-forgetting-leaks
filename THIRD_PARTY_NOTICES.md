# Third-party data, models and code

Nothing below is redistributed in this repository. The code downloads the data and models from
Hugging Face at run time; result files contain model outputs and scores only.

## Dataset

| Item | Source | Licence | How it is used |
|---|---|---|---|
| TOFU (Task of Fictitious Unlearning) | https://huggingface.co/datasets/locuslab/TOFU | MIT | Training (`full`, `retain90/95/99`), forget sets (`forget01/05/10`), evaluation (`*_perturbed`, `holdout01/05/10`, `real_authors_perturbed`, `world_facts_perturbed`) |

Citation: Maini, P., Feng, Z., Schwarzschild, A., Lipton, Z.C., Kolter, J.Z.: TOFU: A Task of
Fictitious Unlearning for LLMs. COLM 2024. arXiv:2401.06121.

`results/*_raw.json` include up to 15 generated answers per split for questions about TOFU's
fictitious authors (and a few real-author / world-fact questions from TOFU). These are model outputs
on MIT-licensed benchmark questions and contain no personal data.
